# @jumper/typescript-config

A copy of `packages/typescript-config` from [joshhornby/anvil](https://github.com/joshhornby/anvil/tree/main/packages/typescript-config).

- `base.json` is the Anvil config. `jumper.d.ts` replaces Anvil's `markdown.d.ts`.
- `react.json` adds the DOM library and JSX for the playground.

Keep `base.json` in step with Anvil when Anvil changes.
